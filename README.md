# OpenTrainAI

A decentralized compute network designed to make consumer-grade GPUs profitable by crowdsourcing AI training, fine-tuning, and inference.

## Core Vision: Democratizing GPU Rewards
Existing AI networks reward only enterprise-grade clusters (A100/H100). OpenTrainAI empowers everyday GPU owners (RTX 3060/4060/4070+) to earn reliable crypto rewards by executing bite-sized AI micro-tasks.

## How Low-Tier GPUs Stay Profitable
- **LoRA & QLoRA Fine-Tuning:** Route lightweight parameter-efficient training tasks optimized for consumer VRAM capacities.
- **Distributed Inference:** Serve API requests for open-source LLMs (e.g., 7B–14B models) during idle compute windows.
- **Data Preprocessing & Embedding:** Earn rewards by executing vector embedding generation, data cleaning, and tokenization.
- **Uptime Subsidies:** Baseline token emissions reward nodes for staying online and ready, softening demand fluctuations.

## Economic Model
1. **AI Developers:** Buy `$OTAI` tokens on exchanges to post training jobs at a fraction of cloud platform rates.
2. **GPU Contributors:** Provide compute power to execute tasks, receiving minted block rewards plus job execution fees.
3. **Halving Schedule:** Token emission rates halve periodically to manage inflation and drive long-term token scarcity.
